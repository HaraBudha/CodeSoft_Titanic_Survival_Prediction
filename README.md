# 🚢 Titanic Survival Prediction

This project predicts whether a passenger survived the **Titanic disaster** using Machine Learning techniques.

## 📊 Features Used

* Pclass (Passenger Class)
* Sex
* Age
* Fare

## 🧠 Model Used

* Logistic Regression

## 🎯 Accuracy

* Achieved accuracy of around **75% – 80%**

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn

## 📌 Conclusion

The model successfully predicts passenger survival based on key features. It shows that factors like gender, age, and class significantly influenced survival chances during the Titanic disaster.
